# 06 — RAG

Build retrieval-augmented generation from first principles.

```text
source → parse → clean → chunk → enrich metadata → embed → index
                                      ↓
query → rewrite → retrieve → filter/rerank → construct context → generate → cite
```

Topics: ingestion, parsing, chunking, embeddings, vector search, keyword search, hybrid retrieval, metadata filters, reranking, query rewriting, context construction, agentic RAG, and evaluation.
