# Learning Roadmap

## Phase 0 — Foundations
- Python for AI engineering
- HTTP/API fundamentals
- Async programming
- JSON, schemas, validation
- Git, Docker, testing
- ML and transformer fundamentals

## Phase 1 — LLM Engineering
- Tokens and context
- Prompt design
- Structured outputs
- Function/tool calling
- Streaming
- Model selection, routing, retries
- Failure modes and safety

## Phase 2 — Agent Fundamentals
- Agent loop from scratch
- Tool execution
- State and context
- Planning
- Memory
- Reflection
- Stop conditions
- Human approval

## Phase 3 — RAG
- Data ingestion
- Parsing and cleaning
- Chunking
- Embeddings
- Vector stores
- Keyword + hybrid retrieval
- Reranking
- Query rewriting
- Context construction
- Agentic RAG
- RAG evaluation

## Phase 4 — Orchestration
- Deterministic workflows
- State machines
- Graph execution
- Branching and parallelism
- Retries and timeouts
- Checkpointing
- Long-running workflows
- Human-in-the-loop

## Phase 5 — Multi-Agent Systems
- Supervisor pattern
- Planner/executor
- Delegation
- Specialist agents
- Debate/critic patterns
- Shared vs isolated state
- When not to use multi-agent systems

## Phase 6 — Evaluation
- Golden datasets
- Task-level evaluation
- LLM-as-judge
- Trace evaluation
- Tool-call evaluation
- RAG evaluation
- Regression suites
- Red teaming

## Phase 7 — Production
- Observability and tracing
- Cost and latency
- Reliability engineering
- Security and prompt injection
- Secrets and permissions
- Sandboxing
- Deployment
- Governance

## Phase 8 — Frameworks
Study frameworks as implementations of the underlying patterns:
- OpenAI Agents SDK
- LangGraph
- LlamaIndex
- Microsoft Agent Framework
- Other relevant agent/RAG frameworks
