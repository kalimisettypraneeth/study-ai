# AWS Certified AI Practitioner — AIF-C01

**Exam date: September 28, 2026**

Beginner-to-exam-ready study path.

## Exam snapshot

AWS currently lists the exam as 65 questions and 90 minutes. It is a foundational certification covering AI, ML, generative AI, AWS AI/ML use cases, responsible AI, and security/governance.

### Domain weighting

| Domain | Weight |
|---|---:|
| 1. Fundamentals of AI and ML | 20% |
| 2. Fundamentals of GenAI | 24% |
| 3. Applications of Foundation Models | 28% |
| 4. Responsible AI | 14% |
| 5. Security, Compliance & Governance | 14% |

Domains 2 + 3 represent 52% of scored content.

## Learning path

```text
AI basics
   ↓
ML basics → metrics → ML lifecycle
   ↓
Generative AI → tokens → transformers → embeddings
   ↓
Foundation Models → prompting → RAG → fine-tuning
   ↓
AWS AI services → Bedrock → SageMaker AI
   ↓
Responsible AI → security → governance
   ↓
Scenario questions → timed mocks → exam
```
