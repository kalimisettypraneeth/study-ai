Prerequisites for AI engineering: Python, HTTP/API fundamentals, async programming, schemas, testing, Docker, ML, and transformer fundamentals.

## What you will understand

- How software systems communicate over HTTP.
- Why async/concurrency needs bounds and backpressure.
- How schemas create reliable boundaries around untrusted data.
- How testing changes when systems become probabilistic.
- How containers make experiments reproducible.
- The mathematical intuition behind embeddings and attention.
